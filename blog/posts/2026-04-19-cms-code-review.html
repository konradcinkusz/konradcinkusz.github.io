Chronic Mild Stress
in Code Review

Pełny artykuł ↓ Pobierz PDF ⎇ GitHub

A translational research article proposing that the everyday feedback culture of software engineering teams — specifically the prevalence of low-effort, non-actionable code review comments such as "why?", "it's strange", or "this feels off" — operationally satisfies the defining criteria of the chronic mild stress (CMS) paradigm from rodent behavioural neuroscience.

The Core Argument

CMS is a well-established animal model of depression: exposing subjects to a sequence of unpredictable, low-intensity stressors produces anhedonia and lasting neurochemical changes. The article argues that the daily drip of vague, non-actionable review comments maps remarkably well onto this paradigm — unpredictable, individually mild, yet chronically present.

The Code Review Stress Index

The article develops a computable exposure metric — the Code Review Stress Index (CRSI) — that can be evaluated directly at the review-tool layer. It classifies comment types, proposes a scoring method, and outlines predicted behavioural phenotypes in affected engineers.

Intervention

The final section specifies a falsifiable intervention: a Justification-or-Deletion policy enforced at the tooling level, requiring that every comment either carry an actionable suggestion or be deleted before submission. The design is deliberately empirically testable.
